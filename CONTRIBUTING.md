# Contributing to PhotoShare

Thanks for your interest in PhotoShare! This repository currently distributes a pre-built Android APK. The application source code is not publicly available at this time, so code contributions (pull requests) aren't possible against this repo. That said, feedback is genuinely welcome and directly useful at this early alpha stage.

## Reporting a bug

Open a [GitHub Issue](https://github.com/Pouria26/Photoshare/issues) and include:
- What you did, what you expected, and what actually happened
- Steps to reproduce, if possible
- Your Android version and device model
- A screenshot, if it helps show the problem

Please check [Known Limitations](README.md#known-limitations) in the README first — some rough edges are already known at this release stage.

## Requesting a feature

Open an Issue describing:
- What you'd like PhotoShare to do
- Why it'd be useful to you (the use case matters more than the exact implementation)

Since this is a personal project still in alpha, the priority right now is stabilizing existing features over adding new ones — but feature requests are read and considered, and popular ones are more likely to make it into a future release.

## General feedback

If something felt confusing, slow, or just not quite right while using the app, that's worth an Issue too, even if it's not a clear-cut "bug." UX feedback at this stage is especially valuable.

## Code of conduct

Be respectful and constructive. This is a personal project maintained in spare time — please be patient with response times.
